Easypanel
=========

[Easypanel](https://easypanel.io) is a self-hosted Docker deployment platform, and NodeBB has a one-click deployment template there.

Initiate Deployment
---------------------

Click the button below to deploy NodeBB on your own Easypanel server.

[![Deploy on Easypanel](https://easypanel.io/img/deploy-on-easypanel-40.svg)](https://easypanel.io/templates/nodebb)

Configuration
--------------

1. Choose a name for the project and service.
2. Review the generated admin credentials and database settings, or customize them.
3. Click "Deploy" to create the NodeBB and MongoDB services.

Utilize NodeBB
--------------

1. Once the services show as running, open the service's domain in your browser.
2. Log in with the admin username and password shown in the service's environment variables.

Congratulations! Your NodeBB instance on Easypanel is now successfully deployed and configured.
